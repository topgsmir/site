## TopGSM UI density

Read [the compact UI guidelines](../../.agents/skills/hallmark/references/topgsm-compact-ui.md)
before designing, changing, or reviewing UI. Future features should use compact
spacing, modest headings, and efficient content layouts, with useful content and
the primary action visible in the first laptop viewport. Apply these project
defaults over generic design-skill suggestions for oversized layouts.
