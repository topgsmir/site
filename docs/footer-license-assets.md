# Footer license images

`PublicFooter` renders four local images in a single row, in the reference's
left-to-right order: eNAMAD, EC Union, Samandehi, and the Internet Businesses Guild.
The images stay on a white background in both themes so the original marks remain
legible. Replace the files in `apps/web/public/images/licenses/` to use the site's
own issued artwork.

Sources:

- eNAMAD: https://github.com/roshana01/digikala-template/blob/master/asset/img/tableqat1%20(3).png
- EC Union: https://github.com/roshana01/digikala-template/blob/master/asset/img/tableqat1%20(2).png
- Samandehi: https://github.com/roshana01/digikala-template/blob/master/asset/img/tableqat1%20(1).png
- Guild: https://eanjoman.ir/assets/favicons/android-chrome-192x192.png

These are static organization logos. No certificate identifier, verification
link, or validity claim has been supplied for Top GSM. Use the site's own issuer
URLs when adding verification links; do not reuse another store's credentials.
